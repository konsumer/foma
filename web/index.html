It crashes, or does not start

          
    
            
  1. Switch the FM-1 off. Hold OCT- and switch it on. The screen says USB RESCUE: no sound, only the updater.
    2. 
            
  2. Install a firmware that works from the Install tab, or the official one below.

A firmware built here that crashes twice while starting goes to the USB rescue by itself. A crash shows a red screen with the address it happened at (look it up in build/fm1/firmware.dis), then the FM-1 restarts.

Nothing reaches it

          
When even the USB rescue does not start, the chip's own boot ROM still can update it, but a browser cannot talk to it (it shows up as a USB disk, which browsers may not touch). From a computer:

          
    
            
  • fm1_rescue.sh (macOS): puts the official firmware back through the boot ROM.
